# Website 2.5 Post-Launch 14-Day Stabilization

## Days 1 to 3
Check daily:
- Production availability
- deployment status
- form delivery
- CRM delivery
- n8n executions
- sitemap
- robots
- redirect errors
- legacy WordPress availability
- 404 spikes
- unexpected Functions
- Security Issues
- Manual Actions

## Days 4 to 7
Check:
- new Search Console indexation findings
- legacy redirect recognition
- Bing sitemap status
- IndexNow responses
- GA4 conversions
- top 404 landing pages
- mobile errors
- Core Web Vitals warnings
- Vercel usage anomalies

## Days 8 to 14
Review:
- indexable URL trend
- legacy URL traffic
- redirect effectiveness
- organic landing pages
- Blog discovery
- form completion
- AI referrals where identifiable
- function usage
- content publishing workflow
- unresolved Important issues
